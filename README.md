Bust-A-Move GG Editor
This tool will let you "paint" levels for Bust-A-Move GG as well as select which background you wish to use.<br>
It will generate an IPS file for this ROM.

## Abilities ##
- Modify the bubble layouts for each level
- Modify the bubble colors themselves
- Modify which background is associated with which level

## Constraints ##
- You cannot edit the boss level (level 100)
- You cannot edit Backgrounds, but rather select from the ones available already to assign to levels
- You cannot modify the length of 100 levels.
- You cannot modify the bubble color PER lvel. it's only global
- You cannot define new bubble types.

## Instructions to Start ##
1) Install `python 3.+`
2) run `pip install Pillow`
3) Run the file from Main
